# S7 against the nine frozen Prototype 1 conditions

Date: 2026-09-30. Scope: read-only source/artifact audit; no new training or validation run and no test-split access. The authoritative nine conditions are in `PROTOTYPE1_MATHEMATICAL_REVIEW.md` §8. S7 is a later, prospectively registered S5 extension, so a Prototype 1 mass-attribution requirement must not be mistaken for an S7 attention control.

| # | Frozen condition | Finding for S7 |
|---|---|---|
| 1 | Full-cloud normalization cached before sampling | **Implemented.** `prepare_camo_cache.py` computes center/scale on the full building and writes metadata; `camo_dataset.py` applies those parameters in `_load_full_arrays` before `__getitem__` samples points. |
| 2 | Surface-mass estimator retains the inverse squared bandwidth factor | **Implemented.** `camo_build/measure.py` computes `rho = kernel.mean(...) / (2*pi*(h2+epsilon))`; the full-building cache calls it. |
| 3 | Exclude self-neighbors | **Implemented.** `camo_build/neighbors.py::scipy_knn_indices` removes the query row even when coordinates duplicate; the fine and proxy graphs use this function. |
| 4 | Cache masses and detach them from autograd | **Implemented.** The dataset loads point-aligned cached masses. `camo_build/s7.py` passes `mass.detach()` to the fine operator and coarsener. The crop's masses are rescaled to mean one after sampling; this does not re-estimate density. |
| 5 | Name the local operator measure-aware, without claiming feature-mass conservation | **Implemented in code; documentation screened.** `camo_build/operator.py` names `LocalMeasureAwareOperator` and explicitly disclaims conservation of the mass-weighted feature integral. `plans/S7_GLOBAL_PROXY_REVIEW.md` and the current LaTeX files do not call the S7 local operator conservative. Historical prose did use that term in `PROTOTYPE1_EXECUTION_REPORT.md`, `paper/STATUS.md`, and `FRONTIER_ARCHITECTURE.md` §13. The first two are corrected; the last is an older proposal and must not be copied into the S7 method. Proxy mass conservation is a separate coarsener property. |
| 6 | Fix positive kernel bounds | **Implemented.** `camo_build/operator.py` defaults to `[0.25, 4.0]` and uses bounded sigmoid output; S7 instantiates that unchanged operator. |
| 7 | Use sparse kNN | **Implemented.** Fine/proxy neighborhoods use SciPy `cKDTree`; the S5 topology adapter supplies S7's proxy graph. No dense `[4096,4096]` kNN path is present in this route. |
| 8 | Include no-mass, uniform-mass and density-mass attribution controls | **Not fully satisfied under the literal frozen condition.** `PROTOTYPE1_EXECUTION_REPORT.md` records no-mass and density 50-epoch runs, but only a one-epoch uniform/no-mass equivalence check. That check supports implementation equivalence, not a 50-epoch uniform-versus-density attribution. S7 did not repeat these three controls: it fixes density mass and compares identity, unweighted MHA and mass-aware MHA under `protocol/mutations/s7_global_proxy_preregistration.json`. S7's measured gain is for the tested global-block change under a density-mass backbone, not evidence that density mass itself caused the gain. |
| 9 | Separate debug and performance gates | **Partially satisfied; not fully satisfied under the literal process requirement.** Synthetic correctness tests are separate from `benchmark_s7.py`, and the benchmark excludes its first four steps from timing while checking finite gradients and VRAM. Yet anomaly detection on the first step and later timed steps run in the same benchmark process; no fresh-process performance repeat is established by this artifact. `runs/s7_dry_run/benchmark.json` records numerical and memory observations, not proof that debug and performance ran in separate processes. |

Conclusion: conditions 1–7 are traceable through the S7 code path, with condition 5 checked against the relevant prose. Condition 8 is **not fully satisfied** under the original three-control attribution wording. Condition 9 is **partially satisfied** and lacks a separate fresh-process performance run. These are reporting and protocol-scope limits; this audit does not alter S7's frozen promotion or test results, and does not reopen S8. No S7 method or result is currently written in the LaTeX manuscript; its existing classification content is a retired pilot and must be rewritten before use.
